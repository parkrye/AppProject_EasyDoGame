# EasyDoGame

인터넷 권한 · 광고 없는 안드로이드 간단 게임 모음. 체스 · 7선 바둑 · 오목 · 당구는 AI 3단계(쉬움 · 보통 · 어려움), 그 밖에 벽돌깨기 · 수박게임 · 2048 · 3매치 · 미니 골프 · 테트리스. 모든 게임 이어하기. 가볍고 빠르게(APK 약 1.3MB), 데이터는 기기 밖으로 나가지 않음.

## 게임

| 게임 | 내용 |
|---|---|
| 체스 | 캐슬링 · 앙파상 · 승진 · 스테일메이트 · 50수 · 3회 반복 등 규칙 완비. 백/흑 선택, 무르기 |
| 7선 바둑 | 7×7, 패 · 자충수 규칙, 중국식 계가(덤 8.5), 종국 시 사석 표시 수정 |
| 오목 | 15×15 자유룰(5목 이상 승, 금수 없음), 두 번 탭 착수, 무르기 |
| 벽돌깨기 | 여러 스테이지, 내구도 있는 벽돌, 목숨 3 |
| 수박게임 | 같은 과일을 합쳐 수박까지, 11단계 과일 |
| 2048 | 4×4 표준 규칙, 스와이프, 무르기 1회 |
| 3매치 | 8×8, 보석 6종(색 + 모양), 연쇄, 30수 제한, 힌트 |
| 미니 골프 | 9홀(벽 · 모래 · 물 · 경사), 당겨서 치기 |
| 당구 | 4구 · 3쿠션 · 8볼, 당점(끌어치기 · 밀어치기 · 좌우 회전), 조준 가이드선. AI 상대 또는 2인 |
| 테트리스 | 표준 7종, SRS 회전, 홀드 · 다음 블록 · 고스트, 버튼 + 스와이프 조작 |

나가거나 앱이 꺼져도 하던 게임을 이어서 진행(새 게임은 버튼으로).

기록: 게임별 플레이 횟수 · 승 · 무 · 패(난이도별) · 최고 점수 · 최소 타수 · 플레이 시간 · 최근 기록. 설정에서 백업 · 복원.

## 설치

[Releases](../../releases)에서 `EasyDoGame-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 기록 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `d0527f3e46788d62f1b40accbc1a95bede62c010ca4cf9805f44a51698e3a3b3`
  (`apksigner verify --print-certs EasyDoGame-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 기록 · 설정은 기기 안에만 저장. 앱 삭제 시 함께 삭제 (Android 클라우드 백업도 끔)
- 앱 안 백업 파일은 사용자가 고른 위치에만 저장. 기기를 바꿀 때는 백업 파일을 옮겨 복원
