# EasyDoGame

광고 · 네트워크 없는 안드로이드 간단 게임 모음. 테마별(보드 · 퍼즐 · 아케이드 · 스포츠) 목록 — 보드: 체스 · 바둑(5~19줄) · 오목 · 리버시(AI 3단계) / 퍼즐: 2048 · 3매치 · 테트리스 10종 · 수박게임 · 지뢰찾기 / 아케이드: 벽돌깨기(클래식 · 숫자 블록) · 점프 러너 · 탭 비행 · 스네이크 · 탑 쌓기 / 스포츠: 미니 골프(기본 · 랜덤 코스) · 당구(4구 · 3쿠션 · 8볼 · 연습). 모든 게임 이어하기 · 게임별 기록. 가볍고 빠르게(APK 약 1.5MB), 데이터는 기기 밖으로 나가지 않음. EasyDo 시리즈.

버그 · 제안은 [Issues](../../issues)에.

## 다운로드

최신 버전 0.2.2 — [Releases](https://github.com/parkrye/AppProject_EasyDoGame/releases)에서 `EasyDoGame-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 기록 · 설정 유지
- 앱 안 `설정 → 앱 정보 → 새 버전 받기`로 Releases 페이지를 열 수 있음 (자동 업데이트 알림 없음)
- 서명 인증서 SHA-256: `d0527f3e46788d62f1b40accbc1a95bede62c010ca4cf9805f44a51698e3a3b3`
  (`apksigner verify --print-certs EasyDoGame-<버전>.apk`로 확인). 각 Release 본문에 APK SHA-256도 기재

## 기능

| 오목 | 15×15 자유룰(5목 이상 승, 금수 없음). AI 쉬움 · 보통 · 어려움. 두 번 탭 착수, 무르기 |
| 리버시 | 8×8 표준 규칙, 끼운 돌 8방향 뒤집기, 둘 곳 없으면 자동 패스 · 양쪽 막히면 돌 수로 승패. 둘 수 있는 칸 표시 · 뒤집기 애니메이션. AI 쉬움 · 보통 · 어려움. 흑/백 선택, 무르기 |
| 2048 | 4×4 표준 규칙, 스와이프, 무르기 1회, 2048 이후 계속 |
| 3매치 | 8×8 · 보석 6종(색 + 모양), 연쇄 배수, 가능한 수 없으면 섞기, 30수로 시작 · 보석 15개 깰 때마다 +1(상한 없음), 힌트 |
| 테트리스 | 표준 7종, SRS 회전 · 월킥, 7-bag, 홀드, 다음 5개, 고스트, 소프트/하드 드롭, 레벨별 낙하 속도, 라인 점수 100/300/500/800×레벨. 버튼(길게 누르면 반복) + 스와이프 |
| 수박게임 | 11단계 과일, 원형 물리(중력 · 충돌 · 마찰), 같은 과일 합치기, 경계선 초과 시 종료 |
| 지뢰찾기 | 쉬움 9×9 · 지뢰 10, 보통 12×16 · 30, 어려움 16×22 · 70. 첫 칸 주변은 항상 안전, 0칸 연쇄 열기, 탭 열기 · 길게 눌러 깃발(열기/깃발 모드 전환), 숫자 칸 탭으로 주변 열기(깃발 수 일치 시). 남은 지뢰 · 경과 시간. 난이도별 최단 시간 |
| 벽돌깨기 | 클래식: 5개 스테이지 패턴 반복, 내구도 1~3 벽돌(회차마다 단단해짐), 목숨 3, 스테이지마다 속도 증가 · 패들 축소. 숫자 블록: 7열 판, 턴마다 블록 3~6개 · 숫자는 턴보다 빠르게 증가, 끌어서 조준 · 공 전부 연속 발사, 맞을 때마다 숫자 -1(0이면 파괴), 처음 바닥에 닿은 공 자리가 다음 발사 위치, 공 +1 아이템, 줄 기믹(가로 · 세로 · 십자), 턴마다 한 줄 하강 · 새 줄 생성, 바닥 줄 도달 시 종료. 회수 · 빨리 감기. 모드별 최고 점수 |
| 점프 러너 | 무한 횡스크롤, 탭 점프(길게 누르면 더 높이) · 아래로 끌기/버튼 숙이기 · 공중 빠른 낙하. 무작위 장애물(작은 · 큰 · 연속 · 낮게 나는 것은 숙여서 회피), 시간에 따라 속도 증가, 점수 = 거리 |
| 탭 비행 | 풍선 캐릭터, 탭 상승 · 중력 낙하. 위아래 기둥 틈 통과 +1, 틈 위치 무작위, 점수에 따라 틈 축소 · 속도 증가, 바닥 · 천장 · 기둥 충돌 시 종료 |
| 스네이크 | 17×23 격자, 스와이프 방향 전환, 먹이마다 길이 +1 · 점수 +1 · 속도 증가. 벽 있음(벽 · 몸 충돌 시 종료) · 벽 없음(반대편으로 이어짐). 모드별 최고 점수 |
| 탑 쌓기 | 좌우로 오가는 블록을 탭해 쌓기, 아래 블록을 벗어난 부분은 잘려 떨어짐, 완전히 빗나가면 종료. 정확히 맞추면 보너스 · 연속 정확 시 폭 회복, 층마다 속도 증가 |
| 미니 골프 | 기본 9홀(벽 · 모래 · 물 · 경사), 당겨서 치기, 홀당 최대 10타, 9홀 총타수. 랜덤 코스: 매번 새로 만드는 9홀(여러 외곽 · 벽 · 블록 · 모래 · 다리 있는 물길 · 경사 · 얼음 · 범퍼 · 풍차 · 순간이동), 홀인 가능한 경로가 있는 홀만 사용, 경로 길이로 파 산정. 코스별 최고 기록 |
| 당구 | 4구(빨간 공 둘 +1, 상대 수구 -1, 10점) · 3쿠션(두 적구 전 쿠션 3회, 5점) · 8볼(그룹 배정 · 파울 · 볼 인 핸드 · 8번 규칙, 콜샷 없음). 당점(끌어치기 · 밀어치기 · 좌우 회전), 수구 근처 당겨 치기 · 드래그 조준 · 미세 조정 · 세기, 가이드선. AI 쉬움 · 보통 · 어려움 · 2인 · 연습(혼자 계속 침, 배치 초기화 · 되돌리기 · 수구 옮기기, 승패 기록 없음) |

이어하기: 나가거나 앱이 꺼져도 하던 게임을 이어서 진행(새 게임은 버튼). 실시간 게임은 일시정지 상태로 복원(탭하여 계속). 이어할 판이 없으면 들어갈 때 설정 창(난이도 · 모드) 또는 시작 창부터 표시.

기록(하단 기록 탭 · 게임 화면 상단 아이콘): 플레이 횟수 · 총 플레이 시간 · 최근 20판, 대전 게임은 난이도별(당구는 2인 포함, 연습은 제외) 승 · 무 · 패, 점수 게임은 최고 점수(골프는 최소 타수, 지뢰찾기는 난이도별 최단 시간, 숫자 블록 · 랜덤 코스 · 스네이크 벽 없음은 따로).

설정:

- `화면`: 배경화면 색 사용(Android 12 이상, 기본 꺼짐)
- `데이터`: 백업 만들기 · 백업에서 복원(파일 하나 `easydogame-backup-yyyy-MM-dd.json`, 복원 전 확인 대화상자)
- `앱 정보`: 앱 정보(버전) · 새 버전 받기(Releases 페이지) · 오픈소스 라이선스
